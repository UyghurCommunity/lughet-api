OpenAPI document ↓
GET /v1/search?q=سۇ

Search words, Latin hints, and English definitions.

GET /v1/suggest?q=sa

Small prefix suggestions for a search field.

GET /v1/words/salam

A complete entry, including provenance and review status.

GET /v1/word-of-the-day

One deterministic word for the current UTC date.

GET /health

Service version, dataset version, and entry count.

Choose the interface you need.

The local adapter works in browsers and Node. The HTTP client accepts your own API deployment and a fetch implementation. Both return data with its source and dataset version.

03 / KNOW THE SOURCE

Small data.
Visible provenance.

The starter collection is original editorial draft work. It has not received independent linguistic review. Definitions are English; Latin forms are lookup hints, not a normative transliteration standard.

Inspect every entry ↓
01

Original and inspectable

33 common words, original draft definitions, a source ID on every record, and a versioned downloadable file. No dictionary was scraped.

02

Honest about its limits

Entries are marked draft. Pronunciation audio is not supplied; audioUrl is explicitly null. The data is a starting point for software and review.

03

Open to better words

Contribute a correction or review through GitHub. Add clear provenance and permission for any new source. Original starter data is dedicated under CC0; code is MIT.
